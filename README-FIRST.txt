TRENDSPARK WEBSITE — UPDATED STATIC SITE

WHAT'S INCLUDED
- index.html: homepage with searchable/filterable story cards
- article-*.html: article pages
- article.css: shared responsive article styles
- about.html, contact.html, privacy.html, disclaimer.html
- robots.txt and sitemap.xml for basic search-engine discovery

HOW TO UPDATE YOUR LIVE CLOUDFLARE WORKER
1. Extract this ZIP on your computer.
2. Open your GitHub repository: trendspark-website.
3. Choose Add file > Upload files.
4. Upload all files from this folder, including the new article pages, article.css, robots.txt and sitemap.xml. If asked, replace existing files. Do not upload the ZIP itself.
5. Commit the changes to the main branch.
6. Cloudflare should build/deploy from GitHub automatically. Check Workers & Pages > trendspark-website > Deployments.
7. Open your public workers.dev URL and test each article link.

IMPORTANT
- This is an editorial starter, not a guarantee of Google AdSense approval or revenue.
- Review all content yourself, add your own expertise/examples, and keep it accurate and current.
- Privacy/contact details should be real and appropriate before collecting data. The newsletter form is a demo and does not collect or send emails.
- Ad placeholders are not ads. Add official AdSense code only after account approval and follow its policies. Never click your own ads or buy fake traffic.
- Sitemap uses the current workers.dev URL. If you later use a custom domain, update the canonical URLs and sitemap.xml/robots.txt to match it.
- Keep index.html and all linked files in the repository root.
